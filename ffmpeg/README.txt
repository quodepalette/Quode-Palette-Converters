FFmpeg folder
=============
ffmpeg.exe is not stored in the git repository because it is larger than GitHub's
100 MB file limit. It is provided in one of two ways:

  * The release zip from the GitHub Releases page includes ffmpeg/bin/ffmpeg.exe.
  * If it is missing, the Audio and Video launchers offer to download it
    automatically the first time you run them.

Binary source: Windows 64-bit GPL build from https://github.com/BtbN/FFmpeg-Builds
FFmpeg project and source code: https://ffmpeg.org/
This build includes GPL components (such as libx264). See LICENSE.txt.
